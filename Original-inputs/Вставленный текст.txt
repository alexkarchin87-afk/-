# 3. РЕЖИМ ULTRA FREE

Это главный функциональный приоритет проекта.

В интерфейсе должен присутствовать переключатель:

**Standard / Ultra Free**

В режиме Ultra Free:

- Не требуется платный API-ключ.
- Не выполняются скрытые платные API-запросы.
- Не используются сторонние неофициальные API ChatGPT.
- Нельзя извлекать cookies, токены авторизации или данные сессий из браузера.
- Нельзя обходить лимиты и ограничения подписок.
- Детерминированные действия выполняются обычным программным кодом.
- Неизвестные запросы не должны выдавать заранее написанные ответы за настоящую работу LLM.

Проверь, существует ли на момент разработки официальный и разрешённый способ использовать лимиты подписки ChatGPT через Sign in with ChatGPT, Codex SDK или другие поддерживаемые механизмы.

**Не предполагай, что обычная подписка ChatGPT Plus автоматически даёт доступ к моделям из любого стороннего приложения.**

Если подходящий официальный механизм существует и разрешает наш сценарий — реализуй его согласно документации.

Если не существует или недоступен — честно укажи ограничение и реализуй Ultra Free как локальный оркестратор инструментов.

Допустимая функция MVP: сформировать запрос для ChatGPT, открыть официальный интерфейс и дать пользователю возможность вручную перенести результат обратно. Это не считается автоматическим подключением LLM.

Никаких ложных обещаний безлимитного бесплатного доступа.

# 4. МУЛЬТИАГЕНТНАЯ СИСТЕМА

Создай архитектуру из трёх компонентов.

### Agent 1 — Planner

Отвечает за планирование задачи.

- Определяет необходимую последовательность действий.
- Выбирает инструменты.
- Проверяет допустимость операций.
- Отслеживает состояние выполнения.

В бесплатной версии используй детерминированный планировщик для поддерживаемых команд.

### Agent 2 — BrowserAgent

Отвечает за браузер:

- Открытие URL.
- Поиск информации.
- Чтение доступного содержимого страниц.
- Выполнение разрешённых действий через Playwright.
- Возврат структурированных результатов.

### Agent 3 — SystemAgent

Отвечает за компьютер:

- Просмотр файлов в разрешённых директориях.
- Запуск приложений из белого списка.
- Проверку состояния компьютера.
- Открытие файлов.
- Изменение обоев после подтверждения.

**Важно:** в Ultra Free эти компоненты не нужно выдавать за три независимые нейросети.

Каждый агент имеет отдельные обязанности, состояние и инструменты. В дальнейшем должен поддерживаться переход на реальные LLM.

# 5. ГРУППОВОЙ ЧАТ АГЕНТОВ

Интерфейс должен позволять наблюдать за выполнением задач.

Пример:

Пользователь:
«Найди три изображения гор Кисловодска для обоев».

Planner:
«Создаю задачу поиска».

BrowserAgent:
«Начинаю поиск».

BrowserAgent:
«Найдены подходящие варианты».

Planner:
«Предлагаю выбрать изображение».

Пользователь выбирает вариант.

SystemAgent:
«Запрашиваю разрешение установить обои».

Пользователь подтверждает.

SystemAgent:
«Обои установлены».

Сообщения должны отражать реальные действия системы, а не выдуманную активность.

Реализуй состояния:

- IDLE
- PLANNING
- RUNNING
- WAITING_APPROVAL
- COMPLETED
- FAILED
- CANCELLED

Добавь идентификаторы задач, тайм-ауты и отмену.

Не допускай бесконечных циклов между агентами.

# 7. ОБЯЗАТЕЛЬНЫЕ СЦЕНАРИИ MVP

Реализуй пять тестовых задач.

**Сценарий 1**

«Открой YouTube на компьютере».

Ожидаемый результат: браузер открывает сайт.

**Сценарий 2**

«Покажи файлы в моей тестовой папке».

Ожидаемый результат: список файлов разрешённой директории.

**Сценарий 3**

«Открой VS Code».

Ожидаемый результат: приложение запускается, если установлено и находится в белом списке.

**Сценарий 4**

«Найди изображения гор для обоев».

Ожидаемый результат: реальные результаты поиска. При отсутствии настроенного поискового источника объясни ограничение. Не выдумывай найденные изображения.

**Сценарий 5**

«Установи выбранное изображение на рабочий стол».

Ожидаемый результат: после отдельного подтверждения Windows устанавливает выбранное изображение.

Сценарии должны работать как из Windows-интерфейса, так и через подключённое Android-приложение, где применимо.
