# Границы безопасности MVP

Сетевой клиент получает доступ только после TLS-проверки полного сертификата, одноразового кода и согласия на ПК.
SHA-256 вводится вне сетевого канала вручную с экрана ПК. Android принимает только совпадающий сертификат с действующим сроком; доверие ко всем сертификатам не используется.
При смене ключа нужно явно повторить сопряжение. Не соглашайтесь на отпечаток из сообщения неизвестного отправителя.

- Сервер по умолчанию loopback; LAN включается указанием конкретного частного IPv4. Нет публичной привязки, UPnP и проброса портов.
- Токены случайные (32 байта), в SQLite хранится только SHA-256. В Android данные зашифрованы AES-GCM ключом Android Keystore, backup/device transfer выключены.
- На Windows сертификат, приватный ключ и SQLite находятся в пользовательском `%LOCALAPPDATA%\VanyaBridge`. Защита файлов зависит от ACL профиля Windows; не переносите их в общую/сетевую папку. `--data` — для локальных тестов/администрирования.
- Приватный TLS-ключ на ПК хранится в PEM под защитой файловых прав профиля, **не DPAPI**. Это ограничение MVP. Доступ администратора/вредоносный код в той же учётной записи не входит в модель защиты.
- История задач содержит запросы/результаты и может содержать личные данные. Она хранится локально в SQLite без шифрования; не отправляйте history.db в диагностические отчёты. Операционный журнал хранит только время, UUID задачи и состояние (до 1000 записей).
- UI показывает последние 50 задач; история на диске пока без автоматической очистки. Контролируйте её размер. Сырые логи HTTP-запросов выключены.
- REST использует bearer header, не query string. Origin браузера отклоняется, CORS не разрешён. Тела POST ограничены 8 КиБ, WebSocket — 8 КиБ, максимум 2 WebSocket на устройство; очередь — 8 задач.
- Read-only по умолчанию. Разрешения можно расширить только локальной кнопкой на ПК; изменения не принимаются из Android API, веб-страницы или чата.
- Каждое изменение/открытие приложения/файла/URL требует подтверждения отдельной задачи. Подтвердить может её устройство-владелец или локальный desktop. Другое устройство не видит и не подтверждает чужие задачи.
- Отзыв устройства аннулирует дальнейшие запросы, прерывает ожидающие/выполняемые задачи и закрывает WebSocket при следующей проверке (до 1 с).
- Один инструмент выполняется за раз. 45 с на очередь+выполнение, 120 с на подтверждение. Отмена не откатывает уже выполненное действие. Синхронный вызов Windows API невозможно гарантированно остановить посередине; визуальное завершение окна не доказывается ответом REQUESTED.
- UUID запроса повторно возвращает принятую задачу; не исполняет её заново. Незавершённые задачи после рестарта помечаются CANCELLED и автоматически не повторяются.
- Shell не вызывается. Code.exe запускается только из белого списка стандартных каталогов, без передаваемых из чата аргументов.
- Пути: только TestFolder, запрет абсолютных путей, `..`, Windows ADS, ссылок/reparse points. Проверка выполняется перед использованием. Не давайте недоверенным локальным процессам изменять эту папку одновременно: отдельного OS sandbox/защиты от всех локальных TOCTOU гонок нет.
- Открытие файлов — только разрешённые расширения; безопасность содержимого PDF/TXT и ассоциированного приложения зависит от Windows и просмотрщика.
- Обои: только JPG/PNG/BMP, до 15 МиБ и 20 Мп; Pillow проверяет формат. Загрузки — только выбранные URL upload.wikimedia.org, без переходов по редиректам. Отменённые/невалидные загрузки удаляются.
- Чтение страниц Playwright — новый профиль, без cookies пользователя, JS/Service Worker/загрузки выключены; сетевые документы ограничены четырьмя официальными доменами, локальные IP отклоняются. Это ограниченный reader, не универсальная браузерная песочница.
- Внешний текст возвращается пользователю как данные. Он не передаётся планировщику для новых действий. Поиск изображений использует только Wikimedia API, не модель.

Android Lint оставляет предупреждение CustomX509TrustManager: это намеренная проверка точного самостоятельно выпущенного сертификата. Тест проверяет принятие правильного отпечатка и отказ при неправильном. Предупреждение не подавлено; необходим независимый security review перед распространением за пределы личного MVP.
Тестирование зависимостей на совместимость выполнено; полноценный анализ всех CVE и проникновения не выполнен.
