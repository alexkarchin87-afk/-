# Локальная модель в VanyaBridge

Обычные поддерживаемые команды выполняются прежними ограниченными инструментами. Неизвестные фразы могут передаваться текстовому адаптеру Ollama только после настройки. Модель не получает инструменты и не может сама выполнять действия. Её ответы могут содержать ошибки.

1. Отдельно установите и запустите Ollama на том же ПК и установите подходящую локальную модель. VanyaBridge не скачивает модели и не запускает Ollama.
2. В приложении откройте «Настройки и устройства», в разделе «Локальная модель» укажите имя модели и нажмите «Сохранить модель». Чтобы отказаться — «Отключить модель».
3. Сообщения вне известной грамматики отправляются на `http://127.0.0.1:11434/api/chat`; никакие ключи API не нужны. Передаются текущая фраза и до четырёх предыдущих пар сообщений локальной модели из той же беседы. Результаты инструментов и сообщения других бесед в контекст не включаются.
4. Настройка применяется и к новым неизвестным запросам сопряжённых устройств. Убедитесь, что ваш Ollama действительно настроен на локальную модель и не перенаправляет запросы в облако: VanyaBridge не может контролировать работу отдельного сервера. Модели с суффиксом `-cloud` отклоняются.
5. Если Ollama не запущен или модель отсутствует, приложение покажет ошибку. На слабом ПК генерация может быть медленной; модель не включена в установщик. После генерации запрашивается освобождение модели (`keep_alive=0`).

Проверка тестовым HTTP-сервером не является проверкой генерации настоящей моделью. Для облачных провайдеров, платных API и многошагового планирования поддержка не добавлена.
