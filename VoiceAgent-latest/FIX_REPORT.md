# Сохранность проекта и дополнительные исправления

Дата: 26 октября 2026. База: VoiceAgent-v2-PROJECT-FOR-APK.zip. Эта поставка содержит полный доступный проект с накопленными исправлениями, но НЕ готовый APK. Модель Vosk остаётся недоступной для переноса в исполнитель.

## Что сохранено

Ни один файл проекта из базового ZIP не удалён. Перед упаковкой проверяется наличие каждого прежнего пути; изменения перечислены в PRESERVATION_FIX.patch и CHANGED_FILES.txt. Все 32 файла группы UI/overlay/STT/TTS/LLM/backend побайтово совпадают с последней поставкой, включая исправления поля ввода и плавающего окна. Прежние исправления отмены запросов, безопасности, сохранения лекций и настроек не откатывались.

Проверка сохранности относится к доступному базовому ZIP. Неизвестный архив пользователя размером 22,7 МБ не был предоставлен, поэтому сравнение с ним не заявляется. Отсутствующие Vosk/APK не заменяются устаревшими или искусственными файлами. Исторические отчёты сохранены в validation/baseline-keyboard-delivery.

## P2 / CONFIRMED — уведомления с одинаковым временем и перевод часов

Файлы: app/.../system/NotificationBuffer.kt, ChatsDigest.kt.
Методы: record, recordsAfter, summarizeSinceLastDigest.

Причина: отметка прочитанного была timestamp. Два поступления могли иметь одинаковое время; перевод часов назад делал новые записи старее отметки. Они пропускались.

Исправление: внутренний монотонный номер поступления. Старые NotificationEntry, record и entriesSince сохранены; старый API timestamp-запроса покрыт отдельным тестом. Пересказ использует внутренний курсор поступлений, не системные часы.

Проверка: усиленный тест поступления во время запроса с тем же timestamp; тест одинакового/более раннего времени; 2 NotificationBufferTest на совместимость старого API и порядок нового курсора. На телефон уведомления не отправлялись.

## P2 / CONFIRMED — обрезанный текст подтверждался целиком

Файлы: app/.../system/ChatsDigest.kt, новый DigestBatch.kt.

Причина: joinToString(...).take(4000) обрезал текст, но отметка сдвигалась на весь снимок. Хвост длинного уведомления и более поздние уведомления после лимита считались обработанными, хотя не попадали в LLM-запрос.

Исправление: формируется порция максимум 4000 символов вместе с предложенной следующей позицией. Продвижение происходит только после успешного LLM-ответа и ensureActive(). Для длинного уведомления сохраняется смещение внутри записи. Следующий пользовательский запрос получает остаток; автоматические дополнительные сетевые вызовы не добавлены. Ошибка/отмена не меняет курсор. Surrogate pair emoji не разрывается на границе порции. Mutex сериализует работу одного объекта пересказа.

Проверка: хвост длинного уведомления, следующая запись после лимита, ошибка на продолжении и повтор того же текста; 4 чистых теста порции, включая emoji и вытеснение частично обработанной записи из буфера. Пять сценариев падали до исправления и проходят после него.

Оставшиеся ограничения: NotificationBuffer по-прежнему хранится в памяти, максимум 200 записей. Смерть процесса и вытеснение старых записей не решены и не объявляются надёжной доставкой. Пересказ части очень длинного сообщения может иметь меньше контекста; сама функция и прежний лимит расходов сохранены.

## P1 / CONFIRMED — Windows-скрипт удалял старую модель до проверки новой

Файлы: scripts/download_vosk_model.ps1, .gitignore; проверки scripts/tests/test_vosk_model.ps1.

Причина: Remove-Item удалял действующую model-ru-small до Expand-Archive и проверки содержимого. Повреждённый/неполный архив оставлял проект без модели. Общие временные имена также создавали конфликт параллельных запусков.

Исправление: отдельная временная папка, проверка безопасных путей ZIP и основных непустых файлов модели, копирование в отдельную staging-папку на файловой системе проекта, эксклюзивный lock и перенос подготовленного каталога. Старый каталог сохраняется в .model-backups/<id>/model-ru-small вне assets и не удаляется автоматически. При неудачном финальном переносе предусмотрен возврат старого каталога. Маркер uuid обновляется для штатного Vosk sync. Добавлен параметр -ModelZip для установки уже имеющегося локального ZIP без сети; прежний запуск без параметров сохраняет загрузку официальной модели.

Проверка: код просмотрен; добавлены 3 автономных PowerShell-проверки (повреждённый ZIP, неполный ZIP, установка с сохранённой резервной копией). PowerShell/pwsh отсутствует: эти проверки НЕ выполнялись. Они не входят в число прошедших тестов. Native-совместимость модели не проверена. Защита от отключения питания не заявляется; после аварии сохранённая резервная копия/lock требуют проверки пользователем.

## Текущее состояние

Kotlin, 141 JVM-тест и Android Lint прошли. assembleDebug остановлен на verifyVoskModel из-за отсутствия реальных assets; новый APK не получен. Ограничение переноса вложения 32 МиБ не является ошибкой исходников и не устранено отключением проверки модели. Нужна передача модели частями либо локальное добавление модели по BUILD_GUIDE_RU.md.

Нельзя утверждать, что исправлены все ошибки приложения. Работа на OnePlus, native Vosk, визуальная геометрия IME/оверлея, реальный Telegram и Windows-скрипт в этой среде не проверялись. Предыдущий вывод об отсутствии встроенного ответа на /start остаётся верным; новая функция ответа не добавлялась.
