# Проверка поля ввода на OnePlus 13

Сначала добавьте полную модель и соберите текущие исходники: `sh gradlew :app:assembleDebug`. Ожидаемый APK — app/build/outputs/apk/debug/app-debug.apk; в этой поставке он не собран. Старый APK не содержит новых UI-правок.

1. Откройте основной экран. Несколько раз откройте/закройте клавиатуру тапом по «Спросите Ваню» и кнопкой «Назад». Поле должно оставаться непосредственно над клавиатурой с небольшим штатным отступом; после закрытия возвращаться вниз.
2. Повторите в пустом чате и с длинной перепиской, с обычной и увеличенной высотой клавиатуры. Список должен уменьшаться/прокручиваться, поле и кнопка отправки оставаться доступны.
3. Введите несекретный черновик, поверните телефон при принудительном режиме «Телефон», верните ориентацию. Проверьте восстановление черновика. При автоматическом переключении на другую раскладку сохранение между разными Composer не гарантируется.
4. Включите разрешение «поверх других приложений» и оверлей. Обычный тап по пузырю должен открывать/закрывать чат; перетаскивание — перемещать его без случайного переключения.
5. Перетащите пузырь к нижнему/правому краю, откройте чат и клавиатуру. Проверьте, что панель помещается в доступной области и поле ввода не закрыто. Закройте клавиатуру: временная коррекция позиции не должна затирать предпочитаемую позицию пользователя.
6. Повторите с длинной перепиской и в горизонтальной ориентации. Проверьте границы окна, доступность кнопки закрытия и отсутствие циклических скачков при анимации клавиатуры.
7. Оставьте открытый чат на 25 секунд, получив ответ ассистента: панель не должна самопроизвольно исчезнуть. Проверьте то же при включённом «показывать всегда». При выключенном этом режиме закрытый пузырь после активности должен по-прежнему скрываться по таймеру.
8. При выключенном агенте отправка текста с основного экрана должна сохранить черновик и показать объяснение неготовности. После запуска отправка кнопкой и IME Send должна работать как раньше.

На OnePlus результаты этого сценария пока UNKNOWN. Если скачок остаётся, полезны: режим основного/плавающего окна, название клавиатуры, ориентация, включённый режим навигации и запись только тестового экрана без личных данных. Не присылайте полные логи/переписку/ключи.
