# Проверки после добавления модели и установки нового APK

1. Повторите KEYBOARD_TEST.md: последние UI/overlay-исправления сохранены побайтово.
2. Создайте два тестовых уведомления с близким временем. Запросите пересказ, затем новое уведомление и повторный пересказ. Новая запись не должна исчезать из-за совпадения timestamp.
3. Проверьте уведомление длиной более 4000 символов: следующий пользовательский запрос должен получить ещё не обработанный остаток. Это не автоматическое чтение всей очереди и не гарантия полноты LLM-пересказа.
4. При сетевой ошибке повторите запрос после восстановления сети, не завершая процесс приложения: неуспешная порция должна снова попасть в обработку.
5. Для Windows сначала выполните `powershell -File scripts\tests\test_vosk_model.ps1` в отдельной рабочей копии. Затем установите свою настоящую модель через -ModelZip либо скопируйте её вручную по BUILD_GUIDE_RU.md. Перед заменой проверьте резервную копию, оставленную в .model-backups; сами тесты применяют только временные fixtures.

В облаке этот сценарий не выполнен. Не отправляйте реальные тексты уведомлений, токены и полные журналы устройства. Для продолжения сборки в облаке нужны все части модели размером менее 32 МиБ каждая; целое вложение не удалось перенести.
