# OnePlus 13 — ручная проверка голосового маршрута

23 октября 2026, Europe/Moscow. Это инструкция, а не протокол выполненного испытания. Телефон к этой среде не подключался.

**Блокер:** приложенный APK собран без Vosk-модели. Официальный сервер модели вернул HTTP 403 через прокси. Для голосового теста скачайте `vosk-model-small-ru-0.22.zip` с `https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip` на своей машине, распакуйте содержимое каталога модели в `app/src/main/assets/model-ru-small/` и пересоберите `./gradlew :app:assembleDebug`. Каталоги `am`, `conf`, `graph` должны находиться непосредственно внутри `model-ru-small`, а не на дополнительном уровне. Gradle создаст `uuid`. Без этого сначала можно проверять текстовый маршрут, но успешное распознавание голоса ожидать нельзя.

1. **Установить APK.** Включить USB debugging, проверить `adb devices`, затем `adb install -r app-debug.apk` (либо установить через системный установщик). Если подпись отличается от установленной версии, не удалять приложение с данными: требуется сборка тем же ключом либо отдельно подготовленный перенос данных. В приложенном архиве APK находится в `APK/VoiceAgent-v2-OnePlus13-debug.apk`.
2. **Подготовить устройство.** Установить официальный Telegram (`org.telegram.messenger`), открыть его вручную. Разрешить Ване микрофон и уведомления; убедиться, что системный выключатель микрофона включён. Проверить русский голос в системном TTS. Для открытия Telegram accessibility/root не нужны. Accessibility требуется для нажатий/жестов; overlay — только если проверяете соответствующий режим. Для длительного фонового теста отдельно проверить настройки батареи OxygenOS.
3. **Запустить агента.** Оставить экран Вани открытым и телефон разблокированным. Убедиться, что нет ошибки загрузки модели и сервис запущен. Запустить запись безопасного диагностического лога на компьютере:
   ```sh
   adb logcat -v threadtime -T 1 'VA_ROUTE:I' '*:S' > voice-route.log
   ```
   Тег `VA_ROUTE` содержит только фазы, фиксированный код ошибки и исход `open_app`; текста речи, ключей, заголовков чатов и тела LLM-ответов в этих записях нет. Не присылайте полный logcat, bugreport или старый crash-log без отдельной проверки содержания.
4. **Одна непрерывная фраза.** Сказать «Ваня, открой Telegram», без паузы после имени. После вопроса агента и окончания озвучки сказать «да». Ожидается одна попытка открытия. Сообщение «Запрос на открытие передан Android» означает только вызов `startActivity`; успешность определяется фактическим появлением Telegram.
5. **Проверить результат глазами.** Зафиксировать, открылся ли Telegram. Для отрицательного теста на устройстве без Telegram агент должен сообщить, что приложение не найдено; при явном SecurityException — об отказе Android. Не считать текст ответа доказательством открытого окна.
6. **Повторить.** Вернуться к Ване, повторить команду и подтверждение: один запуск за один подтверждённый запрос. В отдельном цикле сказать «нет» — открытия быть не должно. Повторное «да» после уже выполненного запроса не должно повторить действие. Также проверить двухчастный вариант «Ваня» → пауза → «открой Telegram».
7. **Прервать ответ и начать заново.** Во время озвучки нажать существующую кнопку остановки агента на экране Вани. Речь/микрофон и ожидающий HTTP-запрос должны остановиться; после нового запуска старый ответ не должен появиться или исполниться. Повторить с длительным облачным ответом только при собственных ключах и согласии на расходы. Отдельных Interrupt/Reset API в этой версии нет: остановка/повторный запуск — проверяемый маршрут. Голосовое «стоп» поверх TTS не поддерживается: сохранён half-duplex, микрофон при озвучке приостановлен.
8. **Потеря сети.** Выключить Wi-Fi и мобильные данные, повторить локальную команду Telegram — она не обращается к LLM. Затем отдельно проверить обычный облачный запрос: должен завершиться ошибкой/тайм-аутом без выключения цикла слушания; один HTTP-запрос с повторами ограничен 210 с, сложная цепочка может включать несколько таких операций. Включить сеть и повторить. Никакие API-запросы этого сценария в облачной среде не выполнялись.
9. **Фон и диагностика.** Только после успешного теста на открытом экране повторить из фона/с заблокированным экраном. Android/OxygenOS могут ограничить фоновый запуск Activity даже при возвращении `startActivity` без исключения. Это отдельный результат, не доказательство ошибки STT. Остановить запись лога Ctrl+C. К отчёту приложить версию Android/OxygenOS, источник APK, последовательность шагов, фактический исход, `voice-route.log`; без API-ключей, переписки и аудио частных разговоров.

Фазы: IDLE — ожидание обращения; LISTENING — запись команды/подтверждения; PROCESSING — обработка; SPEAKING — фактический вызов озвучки. Короткие переходы могут объединяться StateFlow, это не журнал каждой инструкции. Полнословарное распознавание в ожидании обращения может расходовать больше батареи, чем прежняя узкая wake-грамматика; это нужно измерить на телефоне.
