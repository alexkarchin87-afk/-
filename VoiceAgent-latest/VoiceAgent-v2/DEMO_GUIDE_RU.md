# Подготовка демонстрации VoiceAgent-v2 к 9 ноября 2026

Рабочая ветка: `feature/voiceagent-defense-hardening-2026-11-02`. Сначала откройте [карту](ARCHITECTURE_MAP.md) и [отчёт](ARCHITECTURE_REPORT_RU.md). Это Android VoiceAgent-v2; Windows VanyaBridge не нужен для этих проверок.

## Сборка

Откройте `VoiceAgent-latest/VoiceAgent-v2` в Android Studio. Используйте JDK 17, SDK Platform 35 / Build-Tools 34.0.0, Gradle Wrapper 8.9. Kotlin 2.0.21 и AGP 8.7.3 сохранены.

Добавьте настоящую модель Vosk по [BUILD_GUIDE_RU.md](BUILD_GUIDE_RU.md). Не используйте старый APK как результат текущей сборки. Для обновления установленного приложения используйте прежний signing key; не удаляйте приложение вместе с данными ради смены подписи.

Из корня Android-проекта (Windows: `gradlew.bat` вместо `sh gradlew`):

```sh
python3 tools/generate_architecture_map.py --check
python3 -m unittest discover -s tools/tests -v
sh gradlew :app:compileDebugKotlin :app:testDebugUnitTest :core:ai-engines:testDebugUnitTest :app:lintDebug
sh gradlew :app:assembleDebug
```

После успешной сборки APK находится в `app/build/outputs/apk/debug/app-debug.apk`. Для сборки ключи LLM/Telegram не требуются. Для реального облачного запроса нужен настроенный провайдер и ключ в приложении.

## Приёмка на OnePlus 13 (ещё не выполнена)

1. Установите свежий APK с совместимой подписью. Выдайте микрофон и нужные системные разрешения; проверьте диагностику в настройках. Убедитесь, что native Vosk загрузил модель.
2. Без сети введите «открой Telegram»: должен появиться вопрос. «Нет» не открывает приложение. Повторный запрос + «да» передаёт запрос Android один раз. Проверьте отдельно voice, text и overlay: согласие из другого источника не подтверждает голосовой запрос.
3. Выполните облачный запрос. Проверьте проговаривание ответа и возврат к прослушиванию; при отсутствии сети должна быть ошибка, затем локальная команда снова работает. Остановите сервис во время запроса: поздний ответ не должен появиться или начать TTS. Запустите сервис заново.
4. Создайте конспект, дополните его без указания темы, перезапустите приложение и дополните сохранённую тему. Проверьте содержимое файла и обработку сетевого отказа без потери старой версии.
5. Запишите короткую лекцию; остановите голосом. Проверьте локальный транскрипт до/после LLM-резюме и восстановление после сбоя. Не отправляйте чужие записи без согласия.
6. Соберите линейный workflow без чувствительных последствий. Проверьте порядок, ошибочный граф и остановку при ошибке. Не используйте root/отправку сообщений как первый демонстрационный сценарий.
7. Проверьте IME, черновик, overlay и возврат из background по [KEYBOARD_TEST.md](KEYBOARD_TEST.md), [DEVICE_DIAGNOSTICS.md](DEVICE_DIAGNOSTICS.md), [NEXT_DEVICE_TEST.md](NEXT_DEVICE_TEST.md).

TelegramBotService не запускается из текущего UI автоматически; встроенного ответа на `/start` нет. MAX endpoint требует настройки под реальную документацию аккаунта, WhatsApp ограничен текущей реализацией. Не представлять эти интеграции как проверенные на устройстве. Альтернативный `VanyaAutomationEngine` не подключён к активному маршруту; одновременно с VoiceAgentService его не запускать.

Для демонстрации выбирайте только сценарии, которые прошли приёмку на телефоне. Сохраните точную версию коммита, SHA-256 APK, версию Android и фактические результаты. JVM-тесты не заменяют микрофон, native Vosk, Google OAuth и Android background policy.
