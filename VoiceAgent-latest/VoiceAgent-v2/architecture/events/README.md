# События процесса

Владелец: `events`.

## Основные интерфейсы

AgentEvent, AgentEventBus.

## Зависимости

Точные входящие и исходящие связи, файлы и тесты: [ARCHITECTURE_MAP](../../ARCHITECTURE_MAP.md#events). Разрешённые направления: `architecture/components.json`.

## Жизненный цикл

SharedFlow живёт в процессе; подписчики принадлежат своим scope.

## Возможные ошибки

Буфер конечен; публикация может приостановиться; долговечная доставка не гарантируется.

## Тесты

Автономных JVM-тестов нет; нужна проверка Android lifecycle/device.

## Правила расширения

Добавлять типизированные события; учитывать отмену при publish.
