# Что умеет Ваня и как этим пользоваться

Всё ниже — то, что реально реализовано в коде на сегодня (не идеи из
IDEAS.md). Если что-то из этого не сработало — либо не выдано нужное
системное разрешение (см. раздел «Разрешения» в конце), либо стоит
свериться с `MERGE_NOTES.md`, где отмечены хрупкие места.

## Как позвать

- **Голосом**: сказать «Ваня» или «эй, Ваня», затем — команду. Пока
  агент активен, можно продолжать разговор ещё ~20 секунд без повторного
  «Ваня».
- **Текстом**: кнопка-искра в правом нижнем углу открывает панель чата
  с полем ввода — на телефоне на весь экран снизу, на планшете/ПК —
  боковой панелью, в режиме Windows — компактным виджетом в углу.
- **Пузырь поверх других приложений** (нужно включить в настройках,
  разрешение «поверх других приложений»): по умолчанию появляется сам
  на пару секунд, услышав «Ваня», и снова прячется — либо можно
  переключить на «висит постоянно».
- **Быстрые команды**: чипы «Что на экране?», «Что это?», «Что сейчас играет?»,
  «Что нового?», «Заверши лекцию» — прямо в панели чата, без произнесения вслух.

## Что можно попросить

**Разобраться с телефоном**
- «Что на экране и что делать?» — агент читает видимые надписи и кнопки
  текущего экрана и объясняет по шагам, что нажимать. Спрашивает заново
  при каждом вопросе (в том числе на «а что дальше?»), а не по памяти —
  экран мог измениться.
- «Что это?» (когда на экране что-то непонятное — картина, устройство,
  памятник) — вместо инструкции по интерфейсу агент называет, что это, и
  даёт короткую справку в 2-3 предложениях. Работает по видимому тексту на
  экране — если у объекта нет подписи, агент честно скажет, что не может
  определить только по тексту.
- «Открой Х» — открыть приложение или сайт.
- «Сделай громкость 30%» — регулировка громкости медиа.
- «Нажми на Х» / «пролистай вниз» — точечное управление экраном.

**Музыка**
- «Что сейчас играет?» — определяет трек через системные медиасессии:
  работает для любого плеера (Яндекс Музыка, YouTube Music, подкасты),
  не только для одного конкретного приложения.
- «Добавь это в избранное [в Яндекс Музыке]» — открывает Яндекс Музыку
  и нажимает кнопку «Мне нравится» через специальный доступ
  (Accessibility). Это автоматизация интерфейса, а не официальный API
  Яндекс Музыки — если Яндекс переименует кнопку в новой версии
  приложения, может перестать находить её (см. `MERGE_NOTES.md`).

**Лекции**
- «Начни лекцию [по названию]» — начинает запись и распознавание речи.
- «Заверши лекцию» — останавливает запись, лекция сохраняется.
- «Покажи конспект» — краткое резюме последней сохранённой лекции.

**Конспекты из разных источников**
- «Собери конспект по [теме] из этого» (текст лекции/слайдов/фото учебника) —
  оформляет по чёткой структуре: ЗАГЛАВНЫЙ заголовок, нумерация 1./1)/•,
  пояснения терминов в скобках. Прикреплённая схема/картинка вставится в то
  место конспекта, где она нужна по смыслу.
- «Дополни конспект [про X] словами учителя про Y» — находит нужное место в
  уже собранном конспекте и вписывает туда новое, не пересказывая всё заново.

**Что нового**
- «Что нового?» / «че там в чатах?» — короткий пересказ (1-2 фразы) того, что
  накопилось в уведомлениях с прошлого раза: Telegram, WhatsApp, Gmail,
  GitHub, лобби в играх. Флуд не пересказывает, отмечает только суть и то,
  что касается лично пользователя.

**Код**
- «Напиши код/бота/скрипт для …» — генерирует проект, упаковывает в
  .zip, кладёт в Загрузки и присылает карточку с файлом прямо в чат
  (плюс отдельное уведомление с кнопками «Открыть»/«Поделиться»).
- «Поправь/почини/добавь ещё …» — дорабатывает уже сгенерированный
  проект (по умолчанию последний), а не пишет с нуля.

**Память**
- «Запомни, что …» — сохраняет факт о пользователе (используется потом
  в каждом ответе, как контекст). По умолчанию факт долгосрочный, но
  заменяемый (например, класс в школе легко обновится в будущем).
- «Запомни навсегда, что …» / «сохрани железно» — такой факт не пропадёт
  сам по себе ни при каких обстоятельствах, убрать его можно только явным
  «забудь».
- «Забудь, что …» — удаляет конкретный факт (работает и для «навсегда»).
- Весь список того, что помнит агент, виден и редактируем в
  Настройках → «Что помню о тебе» (можно забыть по одному или всё сразу);
  факты «навсегда» помечены отдельно.

**Всё работает?**
- «Всё работает?» / «проверь себя» / «почему не слышишь» — быстрая
  самопроверка: микрофон, доступ к экрану, уведомления, оверлей, оптимизация
  батареи, ключ DeepSeek, Vosk-модель. Голосом — коротко, самое важное;
  полный список с кнопками "исправить" — в Настройках → «Диагностика».

**Всё остальное** — обычный разговор: если запрос не подходит ни под одно
действие выше, агент просто отвечает голосом как ассистент (кратко,
без списков и форматирования — ответ озвучивается, а не читается).

## Отдельно от голоса (не через «Ваня», а через настройки/приложение)

- **Вход через Google-аккаунт** — экран входа при первом запуске.
- **Бот-режим в Telegram/MAX**: отдельная фоновая служба, которая
  отвечает на сообщения, присланные в собственного бота пользователя
  (токен вводится в Настройках) — это не «попроси Ваню написать кому-то»,
  а отдельный канал связи с самим ассистентом.
- **Резервная копия**: Настройки → «Резервная копия» — экспорт/импорт
  всех настроек и секретов одним файлом (например, при смене телефона).
- **Ключи и токены** (DeepSeek API, Claude/Anthropic API, Telegram-бот, MAX)
  редактируются в Настройках без пересборки приложения. Выбора модели
  вручную нет — Ваня сам определяет сложность запроса: простое уходит в
  DeepSeek напрямую, сложное (код, объяснения, многошаговые задачи)
  сначала получает черновик от DeepSeek-R1, а если задан ключ Claude —
  черновик проверяет и правит Claude, и в ответ идёт уже исправленная
  версия. Без ключа Claude сложные запросы просто отвечает один R1.
- **Режим интерфейса** (телефон / боковая панель / Windows-виджет) —
  обычно определяется автоматически по размеру окна, но можно
  переключить вручную в диалоге «Агент и разрешения» (шестерёнка на
  главном экране).

## Если Ваня упал

Приложение само ловит любой краш и сохраняет полный стектрейс в файл —
Настройки → «Если Ваня упал» → «Отправить лог последнего краша». Это
самый быстрый способ починить баг: голый `.apk` без лога чинить приходится
почти вслепую, а по стектрейсу видно конкретную строку конкретного файла.

## Мастерская сценариев (no-code)

Настройки → «Мастерская сценариев» — визуальный конструктор поверх тех же
действий, что Ваня уже умеет по голосу: открыть приложение, громкость, тап
по тексту на экране, пролистать, сказать голосом, пауза. Собираешь цепочку
блоков (перетаскивание + режим «Соединить блоки»), даёшь ей имя и,
опционально, кодовую фразу — тогда сценарий запускается сам, без похода к
LLM, как только фраза прозвучит.

Не хочется возиться со схемой — есть текстовое поле «опиши словами»: то
же самое, что при генерации кода — DeepSeek-R1 собирает черновик, Claude
проверяет (если задан ключ). Голосом работает так же: «собери сценарий,
который...» и «запусти сценарий Х».

`open_app` (и в обычных голосовых командах, и в блоках сценария) понимает
не только точный package («com.spotify.music»), но и обычное название
приложения («Spotify») — сам находит среди установленных.

## Разрешения — что для чего нужно

- **Микрофон** — без него голос вообще не работает.
- **Специальный доступ (Accessibility)** — для «что на экране»,
  «нажми на Х», «пролистай», лайка в Яндекс Музыке.
- **Доступ к уведомлениям** — для «что сейчас играет» (чтение
  медиасессий) и для чтения уведомлений мессенджеров.
- **Показ поверх других приложений** — только для плавающего пузыря;
  без него всё остальное работает как обычно, просто без пузыря.
- **Игнорирование оптимизации батареи** — чтобы голосовой сервис не
  засыпал в фоне.

Все запросы разрешений и переключатели — в одном месте: шестерёнка на
главном экране → «Агент и разрешения».
