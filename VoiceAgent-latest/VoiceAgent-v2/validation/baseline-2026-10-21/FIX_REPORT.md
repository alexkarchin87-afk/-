# VoiceAgent-v2 — отчёт об исправлениях

Дата завершения: 21 октября 2026, Europe/Moscow.

Изменения внесены непосредственно в исходники из `VoiceAgent-v2_P0-first-fix.zip`. Все пункты VA-01–VA-22 сопоставлены с приложенным аудитом и кодом. Архитектура `app → core:ai-engines`, Kotlin/Compose, Vosk, системный TTS, OkHttp, DeepSeek/Claude и дополнительные интеграции сохранены. Исходные файлы проекта не удалены.

Это исправленная инженерная версия, а не подтверждение полной готовности к эксплуатации. Сборка и JVM/backend-тесты не заменяют испытания на Android. Статус отдельных проверок и точные числа — в `TEST_RESULTS.md`.

- Добавлены проверка POST_NOTIFICATIONS и обработка отзыва разрешения перед публикацией project-ready уведомления.
- Для mediaProjection и microphone FGS учтён минимальный API.
- TTS имеет таймаут завершения чанка, одноразовое завершение callback и явные ошибки инициализации/озвучки.

## Изменения поведения

Подтверждение действий добавляет шаг «да/нет». Оно должно прийти после вопроса, в том же канале ввода и в пределах TTL. При неоднозначном получателе сообщение не отправляется. Действия и существующие технологии сохранены, но автоматическое исполнение одного только модельного JSON больше не разрешено.

Для лекции микрофон не конкурирует с wake-word. Во время записи голосовая остановка использует точные фразы «Ваня заверши лекцию» / «Ваня останови лекцию». Остальные команды доступны через текст; на время их обработки/озвучки запись приостанавливается. Это может создавать пропуски во время общения с агентом — выбран явный half-duplex, а не одновременная запись и TTS.

Экспорт теперь зашифрован. Без пароля его восстановить нельзя. Поддержка импорта прежних JSON сохранена. Process-death-атомарность импорта нескольких хранилищ остаётся отдельной незавершённой задачей.

## Что нужно до проверки на телефоне

1. Загрузить официальную русскую Vosk-модель в `app/src/main/assets/model-ru-small/` и пересобрать. Здесь хост `alphacephei.com` вернул HTTP 403 через прокси; модель не подменялась.
2. Ввести свои ключи безопасно через настройки и выбрать поддерживаемые DeepSeek model IDs. Отдельно проверить ordinary/complex/Claude с разрешёнными расходами. Платные API во время этой работы не вызывались.
3. Проверить microphone/уведомления, реальные TTS и echo, многократные overlay show/hide, start/stop сервиса и лекции, отзыв разрешений, блокировку экрана, Android 15+ FGS и OnePlus battery policy.
4. Проверить RemoteInput при одноимённых чатах, смене notification key/version, подтверждении и отмене; экспорт/импорт через системный share sheet на другом телефоне.
5. Выполнить process-kill/disk-full проверки лекций и импорта, длительное измерение Vosk native memory.

Реальных устройств, Android-эмулятора, OAuth-конфигурации Google и ключей API для end-to-end проверки не было. Архив не содержит машинных SDK/JDK-каталогов, Gradle cache, generated build outputs или ключа подписи. Это полный исходный проект с Wrapper, тестами и отчётами; APK не выдаётся за проверенное на телефоне приложение.
