# Review pass (статический разбор перед сборкой APK)

Сборка Android здесь НЕ запускалась (нет SDK и доступа к Google/Maven). Проверено: синтаксис всех
.kt, дубликаты классов, импорты, манифест, ресурсы, зависимости Gradle. Чистая логика (разбор JSON,
да/нет, "спроси Клода") скомпилирована настоящим kotlinc 2.0.21 и прогнана на проверках — все прошли.

## Исправлено
- **Падение сборки:** STTEngine, TTSEngine, LLMClient, SecretsStore лежали и в `:app`, и в
  `:core:ai-engines` (дубли классов). Удалены старые копии из `:app`, живут версии из core.
- **Опасный баг подтверждений:** `classifyYesNo("нет, не используй")` возвращал `true`
  (искалась подстрока). Теперь сравнение по словам, отрицание приоритетнее.
- **"Спроси Клода" с заглавной буквы** не распознавалось (`(?i)` не работает с кириллицей) -> `(?iu)`.
- **extractJsonObject:** теперь пропускает `{` `}` внутри строк (в коде проекта они везде) и
  отрезает хвост после JSON.
- **AgentOrchestrator:** `catch (Throwable)` глотал отмену корутины; убран `!!` (возможный NPE).
- **RootActions:** таймаут 15 с, чтобы запрос root-доступа не вешал вызывающий код навсегда.
- **LectureRecorder:** `stop()` не завершал сбор распознавания (утечка) — теперь отменяет job.
- **CI:** добавлено скачивание модели Vosk (без неё в APK нет распознавания речи) и шаг юнит-тестов
  (`continue-on-error`, APK не блокирует).
- **Секреты:** из архива убраны `local.properties` и `backend/.env` (были реальные значения).
  Примеры остались: `local.properties.example`, `backend/.env.example`.
- **Рефакторинг без изменения поведения:** AgentOrchestrator 771 -> ~650 строк: системный
  промпт -> `AgentPrompts.kt`, чистые парсеры -> `AgentParsing.kt` (можно тестировать без Android).
- **Тесты:** `AgentParsingTest`, `JsonExtractionTest` + зависимости junit / org.json.
- Удалена старая вложенная копия проекта `VoiceAgent-v2/VoiceAgent-v2`.

## Регистрация и разрешения (второй проход)
- Google-вход: причина «не регистрирует» — не зарегистрирован SHA-1 подписи (ошибка 10) и/или CI
  подписывает APK случайным debug-ключом, который меняется каждую сборку. Ошибка теперь показывает
  package name и SHA-1 установленной сборки. Добавлена стабильная подпись (секреты GitHub:
  KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD).
- «Сбрасывается при закрытии»: замок требовал «Продолжить» при каждом запуске; «без входа» не
  запоминалось; файл секретов не был исключён из бэкапа (после переустановки падал). Исправлено.
- Без входа раздел ключей API был скрыт (роль USER) — теперь пока никто не регистрировался,
  владелец = админ.
- Разрешения: фраза «выдай себе все разрешения» + «да» (через root, фиксированный список) и
  `scripts/grant_permissions.sh` для Termux. Добавлено REQUEST_IGNORE_BATTERY_OPTIMIZATIONS.
- Android 13+: для APK не из магазина Accessibility/уведомления серые, пока не включить
  Инфо о приложении -> ⋮ -> «Разрешить ограниченные настройки» (или скрипт выше).
