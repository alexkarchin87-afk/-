# Карта архитектуры VoiceAgent-v2

Генерируется `python3 tools/generate_architecture_map.py`. Семантика и владельцы: [architecture/components.json](architecture/components.json).

Это индекс фактических исходников, не гарантия работы на устройстве. Зависимости — лексические ссылки Kotlin: imports, текущий package и полные имена; reflection, строки и динамические вызовы не анализируются. Wildcard import учитывается консервативно. Столбец «Тесты» — явно зарегистрированные тесты подсистемы, не измеренное покрытие каждого класса.

## Циклы между подсистемами (существующий технический долг)

- Сильно связанная группа: agent, entry, messenger, service, system, workflow, workflow-ui

Границы разрешены явно в реестре. Существующие циклы подсистем не равны циклам Gradle; новые запрещённые направления завершают проверку ошибкой.
