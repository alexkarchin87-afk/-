# Перенос работы в другой диалог — 27 октября 2026

Этот архив сохраняет два разных проекта. **VanyaBridge не заменяет VoiceAgent-v2.**

1. `SESSION_STATE_RU.md` — контекст, выполненные исправления, ограничения и следующий шаг для нового диалога.
2. `VanyaBridge/` — полный исходный MVP, Android APK в `releases/`, инструкции и предыдущие отчёты.
3. `Windows-Portable/` — собранный **Windows x64 VanyaBridge.exe** и ВСЕ файлы его runtime. Запускайте EXE после извлечения всей папки. Python на ноутбуке для этого EXE устанавливать не требуется.
4. `windows-validation/` — журнал сборки EXE, результаты Windows-Python тестов под Wine и снимок реально открытого окна.
5. `VoiceAgent-latest/` — полный последний исправленный VoiceAgent-v2, его отчёты, тесты и патчи.
6. `Original-inputs/` — исходный P0-first-fix ZIP, аудит VoiceAgent и оригинальный текст задания VanyaBridge.
7. `SHA256SUMS.txt` — контрольные суммы всех включённых файлов, кроме самого списка.

Кеши Gradle/pip, виртуальные среды, Wine/Docker, скачанные установщики, wheel-кеши, временные БД, ключи/токены и тестовые пользовательские данные не включены.
Папка `_internal` в Windows-Portable — **не кеш**: это обязательные DLL, Python/Tcl/Tk и Playwright runtime. Не удаляйте её и не переносите один EXE отдельно.
Chromium и Vosk-модель отсутствуют; это явно отражено в SESSION_STATE_RU.md, а не скрыто удалением функций.

## Попробовать на ноутбуке

Извлеките архив целиком. В `Windows-Portable` дважды нажмите `VanyaBridge.exe`.
EXE собран PyInstaller для Windows x64, без цифровой подписи. Его окно проверено под Wine 10; реального Windows 11 / HONOR / OnePlus 13 в среде не было.
Для подключения телефона откройте PowerShell в этой папке и используйте свой частный IPv4:

```powershell
.\VanyaBridge.exe --host 192.168.1.100
```

По умолчанию сервер слушает только 127.0.0.1. При старте с LAN адресом разрешайте доступ только в частной сети Windows.
Дальнейшие шаги сопряжения — `VanyaBridge/README.md`.
Этот README и прежний TEST_RESULTS.md фиксируют первый этап до сборки EXE; **актуальное дополнение о Windows-сборке — SESSION_STATE_RU.md**.

Для необязательного чтения страниц через Chromium, из Windows-Portable:

```powershell
.\_internal\playwright\driver\node.exe .\_internal\playwright\driver\package\cli.js install chromium
```

Эта загрузка требует интернета. На этапе разработки серверы Chromium были заблокированы прокси; браузер не включён в архив.
