## VanyaBridge — отдельный новый проект

Платформы: Android Kotlin/Compose Material 3; desktop Tkinter; backend Python 3.12/FastAPI/REST/WebSocket; Playwright по необходимости; SQLite.
Tkinter выбран для небольшой нагрузки на Core i3 / 8 ГБ, Electron не используется.
Полный пользовательский запрос сохранён в `Original-inputs/Вставленный текст.txt`. Он заканчивается в пункте 14 на середине фразы, но основные требования доступны.

Реализовано:
- Детерминированные Planner, BrowserAgent, SystemAgent. Ultra Free не выдаётся за три нейросети и не обращается к платным LLM.
- Standard показан, но провайдер не настроен; режим честно сообщает об этом. Неизвестная команда не получает выдуманный ответ LLM.
- Поддерживаемые команды: YouTube, список файлов тестовой папки, VS Code, Wikimedia-поиск изображений, выбранное изображение/локальный файл обоев; также статус, разрешённый файл, HTTPS-сайт, ограниченное чтение страниц.
- Состояния IDLE/PLANNING/RUNNING/WAITING_APPROVAL/COMPLETED/FAILED/CANCELLED, UUID задач, очередь до 8, тайм-ауты, отмена, защита от поздних результатов/ошибок и повторного request_id.
- TLS с постоянным самоподписанным сертификатом; Android проверяет полный SHA-256 вне сетевого канала. Одноразовый код, TTL 120 секунд, максимум 5 попыток, подтверждение на ПК и телефоне.
- Bearer-токены: хеш в SQLite, Android Keystore AES-GCM на телефоне. Отзыв устройства отменяет задачи и прекращает доступ.
- По умолчанию loopback; LAN только по явно указанному частному IPv4. CORS не включён, browser Origin запрещён, лимиты POST/WS, нет публичной привязки.
- Изменения/открытие URL/приложения/файла требуют включённого разрешения на ПК и отдельного согласия. Произвольного shell нет.
- TestFolder, проверки путей/ссылок/Windows ADS/reparse points. Изображения проверяются Pillow. Страницы не могут добавлять инструкции планировщику.
- Desktop: вкладки чат/устройства/разрешения/журнал. Android: чат/связь/доступ, lifecycle reconnect, один слой IME padding, черновик сохраняется.

Официальные страницы Codex auth/SDK/ChatGPT plan пытались получить, но прокси отвечал CONNECT 403. Не сделан вывод, что официальный механизм отсутствует; конкретный сценарий интеграции не подтверждён. Нет автоматической авторизации ChatGPT. Ручная кнопка копирует запрос и открывает chatgpt.com.

## Windows EXE — фактический новый результат

Файл `Windows-Portable/VanyaBridge.exe` — настоящий PE32+ Windows x86-64 GUI, не переименованный Linux ELF.
Собран PyInstaller 6.16.0 в режиме onedir/windowed. Нужна вся папка `_internal`.
Вся производственная логика и исходники сохранились без изменений относительно исходного VanyaBridge-MVP-FULL.zip.

Команда сборки:

```text
python -m PyInstaller --noconfirm --clean --onedir --windowed --name VanyaBridge --collect-all playwright --collect-submodules uvicorn desktop_entry.py
```

Среда: Debian trixie container + Wine 10.0 + Xvfb. Исполнялся Windows CPython 3.12.10 x64 из официального NuGet python-пакета.
NuGet Python не содержит Tcl/Tk; добавлены совместимый `_tkinter.pyd` и пакет tkinter из conda-forge Python 3.12.16, Tcl/Tk 8.6.13 из conda-forge. Tk реально импортировался и создавал окно.
Пакеты conda были сверены по SHA-256 опубликованного repodata. Это особенность сборочного окружения, а не модификация кода приложения.
В Wine 8 pip падал на не реализованной propsys.dll.VariantToString. Поэтому окончательная сборка и запуск выполнены в Wine 10; runtime-обход WMI в EXE не добавлялся.
Во время подготовки зависимостей использован pefile 2023.2.7: PyInstaller 6.16.0 исключает проблемную версию 2024.8.26.

Что проверено:
- PyInstaller завершился успешно, лог в windows-validation/pyinstaller.log.
- Непосредственно запущен полученный VanyaBridge.exe, **без** дополнительных TCL_LIBRARY/TK_LIBRARY переменных. Окно Tkinter открылось; скриншот windows-validation/vanyabridge-initial.png.
- Windows-Python тесты под Wine: **43 passed, 1 failed, 1 skipped**. Один skip — тест ограничения Linux-only. Единственный failure — test_symlink_escape: Wine создал ссылку, но её lstat вернул FileNotFoundError вместо ожидаемого тестом ValueError. Доступ к внешнему файлу не произошёл; это не является подтверждением поведения native Windows reparse points. Исходник теста не ослаблялся ради зелёного результата.
- Реальная TLS/REST/WebSocket интеграция под Windows Python/Wine прошла в этом наборе.
- Попытка ввода русской команды через X11 xdotool дала строку `?????? ?????`, и она корректно была отвергнута планировщиком как неизвестная. **Положительная проверка команды через готовый EXE GUI ещё не завершена.** Это ограничение способа автоматизации ввода; не объявлять ввод пользователя на Windows сломанным без воспроизведения.

- Предупреждение сборки: optional hidden import tzdata not found. В текущем коде используется UTC, но полноценную приёмку это не заменяет.
- Chromium не включён и не скачан. Сохранены Playwright driver/node/CLI и все остальные зависимости; инструкция установки браузера — START_HERE_RU.md.

Пользователь прикреплял `vosk-model-small-ru-0.22 (1).zip`, pointer `sediment://file_00000000fd54821194e9599625e35156`.

Нельзя создать пустые model/uuid/fst файлы для обхода Gradle-проверки. Нельзя выдавать старый VoiceAgent APK как новый исправленный.
В наличии был старый OnePlus APK ~28 МБ, но без последних исправлений/модели; в этот архив он намеренно не включён как устаревший исполняемый результат. Его исходники и последующие исправления сохранены в актуальном проекте.

## Правила продолжения

- Работать с реальными файлами, не обещать исправления вместо внесения кода.
- Не удалять работающие функции, не переписывать архитектуру, не подключать платные API и не отправлять исходники/секреты во внешние сервисы без разрешения.
- Разделять CONFIRMED / LIKELY / UNKNOWN; сборка и mocks не доказывают работу на физическом устройстве.
- Пользователь уже разрешил исправления, сборку и необходимые обратимые проверки. Не спрашивать повторные разрешения без реального основания.
- Не запускать агентов-делегатов без явного разрешения; наличие мультиагентной архитектуры приложения само по себе не такое разрешение.
- Для следующих архивов исключать .gradle, build intermediates, .venv, Docker/Wine prefix, wheel/cache, local.properties, .env, реальные key.pem/history.db. Runtime DLL в готовом Windows onedir — обязательные файлы, не кеш.
- Сохранить полноту источников, проверять CRC и SHA-256, честно измерять размер выдаваемого ZIP.
