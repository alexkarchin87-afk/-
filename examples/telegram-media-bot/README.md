# telegram-media-bot (запускается прямо в Termux на телефоне — без ноутбука)

```
pkg install python ffmpeg
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=токен_от_botfather   # НЕ храни его в коде
python bot.py
```

Про авторское право: обёртка над `yt-dlp` — скачивай только то, на что у тебя
есть права, свой контент, или явно разрешённые источники.
